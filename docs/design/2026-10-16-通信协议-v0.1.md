## 背景

定位与架构决策已确认"智能放后端、SDK 变薄协议 client、统一决策端点"。本文档把这一决策落成具体协议（endpoint 清单 + 消息结构），作为后端与 SDK、未来跨语言 SDK 的唯一契约。

契约的机器可读唯一来源是根目录 `openapi.yaml`；本文档只写"为什么与关键语义"，不重复 JSON 定义。

## 设计原则（承接架构决策）

1. **统一决策端点**：Loop Breaker 与 Active Breakpoint 复用同一个 `POST /v1/execution-request`，后端内部两个判断分支，SDK 无感知。
2. **薄 client**：SDK 每次工具调用前同步请求、阻塞等响应；三种决策对应三种动作（见下）。
3. **挂起 = 同步 HTTP 长挂**：断点命中时后端不立即响应，SDK 阻塞在同一 HTTP 请求上等用户决策；SDK 侧无需 WebSocket / asyncio.Event。
4. **WebSocket 只用于后端 ↔ 网页**：推送 trace 生长、断点弹框、熔断告警。

## 端点总览

| 方法 | 路径 | 调用方 | 用途 |
|---|---|---|---|
| POST | /v1/sessions | SDK | 创建调试会话 |
| POST | /v1/execution-request | SDK | 工具调用前决策（核心，可能长挂起） |
| POST | /v1/tool-result | SDK | 工具执行后记录结果（Observation） |
| POST | /v1/thought | SDK | 记录 Thought |
| POST | /v1/sessions/{session_id}/end | SDK | 结束会话 |
| GET | /v1/sessions | WebUI | 会话列表 |
| GET | /v1/sessions/{session_id} | WebUI | 会话详情 + trace 树 + 待处理决策 |
| GET/PUT | /v1/breakpoints | WebUI | 断点配置（SUSPEND 工具 + 熔断参数） |
| POST | /v1/decisions/{decision_id}/resolve | WebUI | 放行/拒绝挂起决策 |
| WS | /v1/stream | WebUI | 实时事件推送 |

## 核心语义

### 1. 决策流程（execution-request）

```
SDK 工具调用前 → POST /v1/execution-request { session_id, tool_name, args }
后端判断：
  ① 滑动窗口熔断命中 → 立即返回 { decision: "reject", reason: "loop" }
  ② 工具在 SUSPEND 名单 → 挂起，等用户 resolve
  ③ 否则 → 立即返回 { decision: "allow" }
```

SDK 对三种响应的动作：

- `allow` → 正常执行工具。
- `reject + loop` → 抛 `AgentLoopException`，终止 agent。
- `reject + human` → 返回失败结果（不抛异常），让 agent 自行走错误分支。

### 2. 挂起机制

命中 SUSPEND 时，后端把该 decision 标记为 pending，**延迟 HTTP 响应**。用户在前端点【放行/拒绝】→ 前端调 `POST /v1/decisions/{decision_id}/resolve` → 后端把挂起的响应返回 allow / reject:human。

- SDK 侧：同步 HTTP 阻塞，默认无限等待（debugger 语义）；可选超时配置（MVP 不做）。
- 挂起期间后端通过 WebSocket 通知前端弹框。

### 3. 降级（关键不变量）

SDK 连接后端失败（看板未启动）时静默降级：execution-request 直接放行、tool-result/thought 不记录、不抛异常、不影响 agent 主流程。

### 4. WebSocket 事件（非 OpenAPI 范畴，此处定义）

| type | payload | 触发 |
|---|---|---|
| node_added | trace 节点 | trace 树生长 |
| decision_pending | decision 摘要 | 断点命中，前端弹框 |
| decision_resolved | decision_id + 结果 | 决策已处理 |
| loop_alert | 熔断信息 | 死循环熔断告警 |
| session_status | session 状态 | 会话状态变化 |

## 已定决策

- **session 显式结束**：SDK 结束时调 `POST /v1/sessions/{session_id}/end`，简单确定，不做"无心跳超时推断"。
