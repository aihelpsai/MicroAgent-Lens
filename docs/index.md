## 编写规范

1. 文件名：`YYYY-MM-DD-<中文摘要>.md`。
2. 每份文档带元信息头：日期 / 版本 / 状态 / 前置阅读（见 template.md）。
3. 单一事实来源：一件事一份权威文档，废弃标注不删。
4. 长文档（预估 > 300 行）分段写（骨架 + Edit），禁止单次 Write 全文。
5. 协议契约以根目录 `openapi.yaml` 为唯一来源，设计文档只写"为什么/语义"，不另写一份对不齐的 JSON。
6. 测试代码放仓库根 `tests/`；测试报告仅在有要求时生成，放 `docs/test/`（记录运行结果，非测试代码），两者不混；测试报告命名沿用 `YYYY-MM-DD-<摘要>`。
