## 后端对接面（阶段 5 前端直接消费，已全部就绪）

### HTTP 端点（openapi.yaml，阶段 3 已实现）

| 前端用 | 方法+路径 | 用途 |
|---|---|---|
| 会话列表 | GET /v1/sessions | 返回 `{sessions:[SessionSummary]}`，`SessionSummary{session_id,status,created_at,tool_count,token_usage}` |
| 会话详情 | GET /v1/sessions/{id} | 返回 `{session:Session, trace:[TraceNode], pending_decisions:[DecisionSummary]}` |
| 断点配置读/写 | GET/PUT /v1/breakpoints | `{suspend_tools:[str], loop_breaker:{window_size,similarity_threshold}}` |
| 放行/拒绝 | POST /v1/decisions/{id}/resolve | body `{action:"allow"|"reject"}` → `ExecutionResponse{decision,reason,decision_id}` |
| 健康 | GET /health | `{status:"ok"}` |

404 响应体是 `{"error": str}`（**非** FastAPI 默认的 `{"detail": str}`）。TraceNode 无 `session_id` 字段（HTTP 的 `_node_dict`）；WS 的 node_added 里 node 含 `session_id`（见下）。

### WebSocket /v1/stream 五类事件（design §4 + app.py 实际 payload）

前端 `new WebSocket("ws://<host>:7878/v1/stream")` 连接后收：

| type | payload 字段 |
|---|---|
| `session_status` | `{type, session_id, status(running\|paused\|ended)}` |
| `node_added` | `{type, session_id, node:{node_id,type(thought\|tool_call\|tool_result),parent_id,created_at,content,session_id}}` |
| `decision_pending` | `{type, decision:{decision_id,session_id,tool_name,args,created_at}}` |
| `decision_resolved` | `{type, decision_id, decision(allow\|reject), reason(loop\|human\|null)}` |
| `loop_alert` | `{type, session_id, tool_name, args, decision_id, created_at}` |

trace 树按 `node.type` 三色区分：`thought` / `tool_call`（Action）/ `tool_result`（Observation）。MVP trace **扁平**（所有节点 `parent_id=None`，阶段 4 D8），前端按 `created_at` 顺序展示即可，不做层级连线。

## 已知坑（阶段 5 必读）

1. **WS payload 字段名**：`decision_resolved` 的事件里「决策结果」字段叫 `decision`（不是 `action`/`outcome`），与 HTTP resolve 请求体 `action` 不同——前端解析时别混。
2. **404 用 `error` 键**：前端错误提示读 `resp.error`，不是 `resp.detail`。
3. **trace 扁平**：`parent_id` 恒 null，前端按 created_at 顺序渲染，别等层级数据（会一直空）。
4. **环境命令用 `.venv` 前缀**：无 `python` 命令；起后端 `.venv/bin/lens serve`（默认 7878）。
5. **`lens serve` 起后浏览器手动验证**：阶段 5 无自动化前端测试（HTML/JS 不进 ruff/mypy/pytest 门禁）；门禁只需存量 `pytest` 不破（不改后端则 96 测试保持全绿）。验收是浏览器人工走四功能。
