## 2. 关键实现决策（本阶段新增，与路线 §5 不冲突）

1. **CLI**：`argparse` 标准库，`lens` 下挂 `serve` 子命令（`subparsers` + `required=True`），`serve` 带 `--host`（默认 `127.0.0.1`）与 `--port`（默认 `7878`，`type=int`）。不引 click/typer。
2. **启动方式**：`uvicorn.run(app, host=..., port=...)` 传 app 对象（编程式）。若 mypy strict 对 app 参数类型告警，降级用字符串形式 `uvicorn.run("lens.server.app:app", ...)`。
3. **app 形态**：模块级 `app = FastAPI(title="microagent-lens", version="0.1.0")`，两个路由 `@app.get("/")`（返回 `{"service": "microagent-lens", "version": "0.1.0"}`）与 `@app.get("/health")`（返回 `{"status": "ok"}`）。
4. **smoke 测试**：`fastapi.testclient.TestClient`（依赖 `httpx` 已在运行时依赖，无需新增）。pytest 不真起 uvicorn；`lens serve` 起服冒烟放收尾 gate 手动做。
5. **webui 打包**：`lens/webui/index.html` 属 `lens` 包内数据文件，editable 安装下可直接读；正式 package-data 打包留阶段 6，本阶段不动 pyproject。

## 3. mypy strict 已知坑（实现时注意，勿反复踩）

- argparse：`parser.parse_args()` 返回 `Namespace`，属性访问（`args.command` / `args.host` / `args.port`）在 strict（`disallow_any_expr`）下会告警 `Expression has type "Any"`。方案：`from typing import cast` 后 `command = cast(str, args.command)` 再使用；或对整行 `# type: ignore[no-any-expr]`。计划采用 `cast` 方案，代码更干净。
- 所有函数必须带完整类型注解（`def main() -> None:`、路由 `def root() -> dict[str, str]:` 等）。

## 4. Task 拆分（1 个 task + 收尾 gate）

> B 路径规模最小形态：8 个文件、零逻辑，1 个子代理 task 即可，收尾 gate 在主会话做。确认后进 worktree（`EnterWorktree`）执行。

**Task 1（单一职责：最小可跑框架，test-first，子代理 `model: sonnet` 一次完成）**

1. 先写 `tests/test_smoke.py`（导入 `lens.server.app`、TestClient 断言 `/` 与 `/health` 200）→ 跑 `pytest` 看 RED（`ModuleNotFoundError: lens`，因包未建）。
2. 写 7 个骨架文件 → 跑 `pytest` 看 GREEN。
3. 本地 `ruff check .` + `mypy lens` 绿 → commit。

子代理 prompt 显式约束：只做本 task 范围、test-first（先见 RED）、完成即 commit、不碰 pyproject、不写任何决策逻辑。

**收尾 gate（主会话，不派子代理）**

按顺序跑并贴出命令输出：

```bash
pip install -e ".[dev]"
ruff check .
mypy lens
pytest
lens serve            # 起服，另开终端 curl -s localhost:7878/ 有响应后停服
```

## 5. 验收判据（退出 gate，全部满足才完成）

1. `pip install -e ".[dev]"` 成功（无报错，`lens` 命令可解析到 `lens.cli:main`）。
2. `lens serve` 起服务，`curl -s localhost:7878/` 有响应（200，含 service/version JSON），手动 Ctrl+C 停服。
3. `ruff check .` 0 error。
4. `mypy lens` 0 error（strict）。
5. `pytest` 全绿（1 个 smoke，≥2 断言）。
