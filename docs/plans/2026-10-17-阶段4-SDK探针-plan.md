## 1. 目标与范围

做薄协议 client + 装饰器 + 降级 + 三语义分派。决策引擎全在 server（阶段 2/3 已完成，69 测试全绿）；SDK 只「发 HTTP + 阻塞等响应 + 按响应分派」。

**交付物**：`lens/sdk/client.py`、`lens/sdk/errors.py`、`lens/sdk/trace.py`、`lens/sdk/decorators.py`、`lens/__init__.py`、`tests/`（4 个新测试文件）。

**退出判据**：降级测试（连不上不抛异常、返回 allow）+ 三语义测试（allow 执行 / reject:loop 抛 `AgentLoopException` / reject:human 抛 `ToolRejected`）+ 门禁全绿。

## 2. 设计决策

| # | 决策 | 方案 | 理由 / 来源 |
|---|---|---|---|
| D1 | 公共 API 集合 | 导出 **6 项**：`start_session` / `end_session` / `bind_tool` / `log_thought` / `AgentLoopException` / `ToolRejected` | 路线 §4 说「三公共 API」，但 suspend 声明合并（§5 决策）+ session 显式结束（design 已定决策）+ ToolRejected 需被 agent 捕获，硬需求补出 3 项。标注为对路线的补充，非违背 |
| D2 | client 形态 | `LensClient` 类（同步 `httpx.Client`），构造参数 `base_url` / `timeout` / `transport`（测试注入 `httpx.MockTransport`）；`execution_request` 返回 `ExecutionResponse` frozen dataclass | 可测性：transport 注入让降级/三语义测试零依赖 mock；dataclass 类型安全 |
| D2b | timeout 分端点 | `execution_request` 用 `timeout=None`（**无限等待**，断点挂起语义）；其余端点用构造默认 timeout（超时即降级） | design §2「同步 HTTP 阻塞，默认无限等待」；统一 10s 会让断点挂起超时降级为 allow，破坏断点 |
| D3 | 降级语义 | 所有方法 `resp.raise_for_status()`（404/5xx → `HTTPStatusError`），捕获 `httpx.HTTPError`（ConnectError / TimeoutException / HTTPStatusError 等）；`execution_request` 降级返回 `ExecutionResponse("allow", None, "")`、`create_session` 返回 `None`，其余端点静默返回 `None` | 不变量 1；httpx 不会自动抛 404，须 raise_for_status 才进降级；SDK 永不因后端不可达让 agent 崩溃 |
| D3b | 静默 = 吞一切 | 五个「静默」端点（tool_result / thought / end / breakpoints×2）内部吞**所有**异常，含 json 序列化 `TypeError`（`json=` 对不可序列化 result 抛 TypeError，非 HTTPError） | 序列化失败若冒泡会被 decorator 的 except 误吞 →「工具成功记为失败 + TypeError 上抛」，必须内部预检/吞掉 |
| D4 | 三语义分派 | allow→执行+记录 tool_result；reject:loop→抛 `AgentLoopException`；reject:human→抛 `ToolRejected` | 不变量 4；**以路线 §5 为准**——design §1「返回失败结果（不抛异常）」是旧表述，§5 已改为「抛 ToolRejected 专用非致命异常（不终止 agent）」 |
| D5 | 工具异常传播 | 工具抛异常→记录 `tool_result(ok=False, error=str(e))`→`raise` 原样重抛 | 记录失败 Observation，但**不吞** agent 异常 |
| D6 | args 构造 | `inspect.signature(func).bind(*args, **kwargs)` 的 `arguments` 作为 `args`；`tool_name = func.__name__` | 参数名 dict 稳定可读，熔断相似度比较有意义；参数需 JSON 可序列化（否则 httpx 序列化 TypeError 冒泡，属 agent 契约） |
| D7 | suspend 声明合并 | 模块级 `set` 收集 `@bind_tool(suspend=True)` 工具名；`start_session` 时 GET breakpoints→并集→PUT；降级跳过。**合并在 SDK 侧** | 阶段 3 交接红线：后端 PUT 是覆盖语义，不加 merge 端点。suspend 名单后端为**进程级全局**（非 per-session）；MVP 假设 start_session 前所有 `@bind_tool` 已装饰（模块已 import），之后才装饰的 suspend 工具不进当前 session 名单 |
| D8 | trace 扁平 | MVP trace 无 parent_id（openapi 的 thought/tool-result 端点无 parent_id 字段，后端 add_node 均 parent_id=None）。trace.py 只做 contextvars 当前 session_id 管理 | 契约不支持；父子关联随 llm 节点后置（框架适配器阶段） |
| D9 | session 生命周期 | `start_session(metadata)`：create_session + 合并 suspend + 写 ContextVar，后端不可达返回 None（降级）；`end_session()`：**必清 ContextVar** + 尽力 POST end（失败静默） | design 已定决策「session 显式结束」；清 contextvar 是必然动作、POST 是尽力而为；ContextVar 线程/协程安全 |
| D10 | result 序列化 | tool_result 组装前 `json.dumps(result)` 预检，失败则降级为 `repr(result)` 字符串（保留信息且必可序列化） | 不变量 1 的延伸；MVP 不递归序列化对象，repr 兜底 |
| D11 | 测试策略 | `httpx.MockTransport` mock 后端响应（零新依赖），测三语义+降级+suspend 合并+contextvars；真联调留阶段 6 | 路线 §6「阶段 4 用 mock 测，真联调统一放阶段 6」 |
| D12 | base_url 配置 | 默认 `http://localhost:7878`，环境变量 `LENS_BASE_URL` 覆盖 | 读环境变量是配置非可变状态；零配置优先 |

## 3. 模块设计

### 3.1 `lens/sdk/errors.py`

```python
class AgentLoopException(Exception):
    """死循环熔断：reject:loop。终止 agent，顶层捕获后停止。"""
    def __init__(self, decision_id, tool_name, args): ...

class ToolRejected(Exception):
    """断点被拒绝：reject:human。专用非致命异常，agent 捕获走错误分支。"""
    def __init__(self, decision_id, tool_name, args): ...
```

两异常均带 `decision_id` / `tool_name` / `args` 属性，供 agent 记录。继承 `Exception`，`ToolRejected` 与 `AgentLoopException` **不**同源（不搞基类），保证 agent 能精确区分「终止 vs 非致命」。

**实现注意（Task 1 已落地，commit 5f685c1）**：
- `args` 与 `BaseException.args`（C 层 getset，赋值强转 tuple）冲突：用 property 覆盖 `args`（getter 返回 `_tool_args: dict[str, Any]`，setter 回写）+ `# type: ignore[override]`（mypy strict 报 override 不兼容）；构造内 `super().__init__(msg)` 先行、再 `self.args = 工具参数 dict`。`str(exc)`/`repr(exc)` 仍走 C 层消息元组。decorators 只 `raise`、不读 `.args`。
- 异常名不以 `Error` 结尾触发 ruff N818：类行 `# noqa: N818`（契约名 vs lint 惯例冲突）。

### 3.2 `lens/sdk/client.py`

```python
DEFAULT_BASE_URL = "http://localhost:7878"

@dataclass(frozen=True)
class ExecutionResponse:
    decision: Literal["allow", "reject"]
    reason: Literal["loop", "human"] | None
    decision_id: str

class LensClient:
    def __init__(self, base_url: str = DEFAULT_BASE_URL, timeout: float = 10.0,
                 transport: httpx.BaseTransport | None = None) -> None:
        self._client = httpx.Client(base_url=base_url, timeout=timeout, transport=transport)

    def create_session(self, metadata: dict | None = None) -> str | None: ...
    def execution_request(self, session_id, tool_name, args) -> ExecutionResponse: ...  # timeout=None 覆盖，无限等待
    def tool_result(self, session_id, tool_name, ok, result=None, error=None, duration_ms=None) -> None: ...
    def thought(self, session_id, content) -> None: ...
    def end_session(self, session_id) -> None: ...
    def get_breakpoints(self) -> dict | None: ...
    def put_breakpoints(self, suspend_tools, loop_breaker=None) -> dict | None: ...
    def close(self) -> None: ...


_default_client: LensClient | None = None


def get_default_client() -> LensClient:
    """惰性单例，trace.py / decorators.py 共用；读 LENS_BASE_URL。测试 monkeypatch 此处注入。"""
```

**关键约束**：
- 每个方法 `resp.raise_for_status()` 后解析；`try: ... except httpx.HTTPError: <降级>`。`create_session` 降级返回 `None`，`execution_request` 降级返回 `ExecutionResponse("allow", None, "")`，其余返回 `None`。
- `execution_request` **覆盖 `timeout=None`**（无限等待，断点挂起语义）；其余端点用构造默认 timeout。
- 「静默」端点（tool_result / thought / end / breakpoints）内部吞**一切**异常（D3b），含 result 序列化预检（D10），保证绝不抛。
- `execution_request` 解析 `resp.json()` → `ExecutionResponse(decision, reason, decision_id)`，字段取值 `cast`（mypy strict）。
- `get_breakpoints` / `put_breakpoints` 是 D7 的支撑（SDK 侧合并用）；`put_breakpoints` 只发 `suspend_tools` + `loop_breaker`。
- 无决策逻辑：不 import `lens.server`，不做熔断/断点/相似度判定。

### 3.3 `lens/sdk/trace.py`

```python
_current_session: ContextVar[str | None] = ContextVar("lens_session", default=None)
_suspend_tools: set[str] = set()  # 装饰时收集，非运行时可变


def register_suspend_tool(name: str) -> None:
    """bind_tool(suspend=True) 装饰时登记工具名。"""
def _declared_suspend_tools() -> frozenset[str]: ...


def start_session(metadata=None, client=None) -> str | None:
    """create_session + 合并 suspend 名单 + 写 contextvar；后端不可达返回 None。"""
def end_session(client=None) -> None:
    """POST end + 清 contextvar；无 session 或降级静默。"""
def current_session_id() -> str | None: ...
def log_thought(content: str) -> None:
    """无 session 或降级时静默。"""
```

**关键约束**：
- **import 方向单向**：decorators → trace → client（无循环）。suspend 声明的收集/读取放 trace.py（`register_suspend_tool` / `_declared_suspend_tools`），decorators 只登记、不持有集合——若把集合放 decorators 会造成 trace↔decorators 循环 import。
- `client=None` 时用 `get_default_client()`（§3.2）；测试注入 mock client 或 monkeypatch `client.get_default_client`。
- `start_session` 流程：`sid = client.create_session(metadata)`；`sid is None` → 直接返回 None（降级）；否则 `merged = _declared_suspend_tools() | 现有名单`（GET→并集→PUT，D7）；写 `_current_session.set(sid)`；返回 sid。
- `end_session`：**先清 `_current_session`（必然动作）**，再尽力 `client.end_session(sid)`（失败静默）。
- `log_thought` 无 session 直接 return（不抛）。

### 3.4 `lens/sdk/decorators.py`

```python
def bind_tool(suspend: bool = False):
    def decorator(func):
        if suspend:
            register_suspend_tool(func.__name__)  # 收集在 trace.py（§3.3）
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            sid = current_session_id()
            if sid is None:
                return func(*args, **kwargs)   # 未 start_session：降级直接执行
            bound = inspect.signature(func).bind(*args, **kwargs)
            client = get_default_client()
            resp = client.execution_request(sid, func.__name__, dict(bound.arguments))
            if resp.decision == "allow":
                try:
                    result = func(*args, **kwargs)
                except Exception as e:
                    client.tool_result(sid, func.__name__, ok=False, error=str(e))  # 内部吞，不抛
                    raise
                client.tool_result(sid, func.__name__, ok=True, result=result)  # 内部吞，不抛
                return result
            if resp.reason == "loop":
                raise AgentLoopException(resp.decision_id, func.__name__, dict(bound.arguments))
            raise ToolRejected(resp.decision_id, func.__name__, dict(bound.arguments))
        return wrapper
    return decorator
```

**关键约束**：
- `bound.arguments` 需 `dict()` 化（`inspect.BoundArguments` 不是纯 dict，mypy 严格需转换）。
- `client` 通过 `get_default_client()` 获取（§3.2）；测试 monkeypatch 注入。
- **成功分支的 tool_result 在 try 外**，失败分支在 except 内；两处 tool_result 内部都吞异常（D3b）——避免 result 序列化失败被工具异常 except 误吞。
- suspend 声明收集在**装饰时**（模块加载即收集），经 `register_suspend_tool` 登记进 trace.py；`start_session` 读 `_declared_suspend_tools()`（D7）。
- 三语义分派是 SDK 仅有的「判断」，但它是**协议响应分派**（按后端返回的 decision/reason 分派），非决策逻辑，不违反不变量 2。

## 4. SDK 端点契约（对照 openapi.yaml，只读）

| SDK 方法 | HTTP | 请求体 | 响应（200） | 降级 |
|---|---|---|---|---|
| create_session | POST /v1/sessions | `{metadata?}` | `Session{session_id,...}` | 返回 None |
| execution_request | POST /v1/execution-request | `{session_id,tool_name,args}` | `ExecutionResponse{decision,reason,decision_id}` | allow 哨兵 |
| tool_result | POST /v1/tool-result | `{session_id,tool_name,ok,result?,error?,duration_ms?}` | `{}` | 静默 |
| thought | POST /v1/thought | `{session_id,content}` | `{}` | 静默 |
| end_session | POST /v1/sessions/{id}/end | — | `Session` | 静默 |
| get_breakpoints | GET /v1/breakpoints | — | `{suspend_tools,loop_breaker}` | 返回 None |
| put_breakpoints | PUT /v1/breakpoints | `{suspend_tools,loop_breaker}` | 配置 | 静默 |

404 响应 `{"error": str}`，SDK 统一 `raise_for_status()` 使 404/5xx 抛 `HTTPStatusError` → 进 D3 降级（create_session 返回 None、execution_request 返回 allow、其余静默）；MVP 不区分 404 vs 5xx（SDK 不依赖后端正确性）。

## 8. 红线（勿越界）

1. **不 import `lens.server`**：SDK 与 server 是 HTTP 契约关系，禁止 import 任何 server 模块（不变量 2）。
2. **不改 openapi.yaml**（契约唯一来源，只读）。
3. **不加后端 merge 端点**：suspend 合并只在 SDK 侧做（D7）。
4. **不做 webui**（阶段 5）、**不做 CLI 补全/端到端示例**（阶段 6）。
5. **不新增依赖**：httpx 0.28 已装，MockTransport 内置。
6. **不用 worktree、不强制 formal review**（延续阶段 1 决策 1/3），直接 main 分支实现。
