## 2. 关键实现决策（本阶段新增，与路线 §5 不冲突）

1. **滑窗语义（历史作入参）**：判定函数签名 `should_break(recent_calls, current, window_size, threshold)`。`recent_calls` 是窗口内最近 `window_size-1` 次调用（不含当前），当前调用凑满 `window_size` 次连续同名同参即熔断。窗口本身的维护由阶段 3 调用方负责（从 decisions 表取最近 N 次），本阶段只提供纯判定，不做任何存储或状态。
2. **同名 = 名字全等；同参 = 参数相似度达标**：`tool_name` 字符串精确相等；参数先 `json.dumps(args, sort_keys=True)` 再 `SequenceMatcher.ratio() >= threshold`。名字不参与相似度计算。
3. **args 序列化沿用已确认决策** `json.dumps(args, sort_keys=True)`。注意 `sort_keys` 只排顶层 key，嵌套 dict 的 key 顺序不保证稳定——记为已知边界，MVP 不做递归排序（不扩 scope）。
4. **状态机用 `Literal` 类型别名 + 显式合法流转表**，非法流转抛 `ValueError`。不引 `enum`/`StrEnum`（避免过度抽象，Literal 已够）。
5. **store 用 `Store` 类持有不可变 `db_path`**，每个方法内部 `sqlite3.connect(db_path)` 开独立连接、用完即关（落实路线 §5「每请求独立连接」）。类无持久连接字段，故无全局可变状态。
6. **时间戳统一** `datetime.now(timezone.utc).isoformat()` 存 TEXT（对齐 openapi `format: date-time`）。
7. **JSON 字段**（`sessions.metadata` / `trace_nodes.content` / `decisions.args`）存 TEXT（`json.dumps` 写入、`json.loads` 读回），`content` 支持任意 JSON 类型（对齐 openapi `content: 任意 JSON`）。
8. **CRUD 的 D（delete）不实现**：三表只提供 create / read / update（update 即状态流转），符合「删预留」约束。

## 3. 数据模型设计

### 3.1 SQLite schema（`store.py` 的 `init()` 建表，全部 `IF NOT EXISTS`）

```sql
CREATE TABLE IF NOT EXISTS sessions (
  session_id TEXT PRIMARY KEY,
  status     TEXT NOT NULL,           -- running | paused | ended
  created_at TEXT NOT NULL,           -- ISO 8601 UTC
  ended_at   TEXT,                    -- NULL 直到 ended
  metadata   TEXT                     -- JSON 字符串，可空
);

CREATE TABLE IF NOT EXISTS trace_nodes (
  node_id    TEXT PRIMARY KEY,
  session_id TEXT NOT NULL REFERENCES sessions(session_id),
  type       TEXT NOT NULL,           -- thought | tool_call | tool_result
  parent_id  TEXT REFERENCES trace_nodes(node_id),  -- 可空
  created_at TEXT NOT NULL,
  content    TEXT                     -- JSON 字符串（任意 JSON 类型）
);

CREATE TABLE IF NOT EXISTS decisions (
  decision_id TEXT PRIMARY KEY,
  session_id  TEXT NOT NULL REFERENCES sessions(session_id),
  tool_name   TEXT NOT NULL,
  args        TEXT NOT NULL,          -- JSON 字符串
  status      TEXT NOT NULL,          -- pending | allowed | rejected
  reason      TEXT,                   -- loop | human，仅 rejected 有值
  created_at  TEXT NOT NULL,
  resolved_at TEXT                    -- NULL 直到 resolved
);

CREATE INDEX IF NOT EXISTS idx_trace_nodes_session ON trace_nodes(session_id);
CREATE INDEX IF NOT EXISTS idx_decisions_session ON decisions(session_id, status);
```

索引：`trace_nodes.session_id`（列表查询）、`decisions(session_id, status)`（pending 过滤查询）。

### 3.2 状态机（合法流转表，Python 层校验，非法抛 `ValueError`）

**sessions**（`running` → `paused` → `running` → `ended`，`ended` 终态）：

| 当前 | 允许去向 |
|---|---|
| `running` | `paused`, `ended` |
| `paused` | `running`, `ended` |
| `ended` | （无） |

- 同状态重复设置 = no-op（幂等）；跨到「不允许去向」抛 `ValueError`。
- 置为 `ended` 时同时写 `ended_at = now`。

**decisions**（`pending` → `allowed` / `rejected`，两者终态）：

| 当前 | 允许去向 | reason 约束 |
|---|---|---|
| `pending` | `allowed`, `rejected` | `allowed`→reason 必须 None；`rejected`→reason 必须 `loop`/`human` |
| `allowed` | （无） | — |
| `rejected` | （无） | — |

- 流转到 `allowed`/`rejected` 时写 `resolved_at = now`。
- 与 sessions 一致：同状态重复设置 = no-op（幂等），非法跨状态抛 `ValueError`。

> 补充（review 后补强）：`set_session_status` / `transition_decision` 在目标行不存在（UPDATE 影响 0 行）时抛 `ValueError`，保证阶段 3 能把「资源不存在」正确映射为 404；`create_*` 主键冲突由 `sqlite3.IntegrityError` 自然抛出，不额外包装。

### 3.3 数据类（frozen dataclass，映射行，放 `store.py`）

```python
SessionStatus = Literal["running", "paused", "ended"]
NodeType      = Literal["thought", "tool_call", "tool_result"]
DecisionStatus = Literal["pending", "allowed", "rejected"]
DecisionReason = Literal["loop", "human"]

@dataclass(frozen=True)
class Session:
    session_id: str
    status: SessionStatus
    created_at: str
    ended_at: str | None
    metadata: dict[str, Any] | None

@dataclass(frozen=True)
class SessionSummary:               # list_sessions 返回，含 tool_count
    session_id: str
    status: SessionStatus
    created_at: str
    tool_count: int                 # 该会话 type='tool_call' 的 trace_nodes 计数

@dataclass(frozen=True)
class TraceNode:
    node_id: str
    session_id: str
    type: NodeType
    parent_id: str | None
    created_at: str
    content: Any                    # json.loads 后任意 JSON

@dataclass(frozen=True)
class Decision:
    decision_id: str
    session_id: str
    tool_name: str
    args: dict[str, Any]            # json.loads 后
    status: DecisionStatus
    reason: DecisionReason | None
    created_at: str
    resolved_at: str | None
```

class Store:
    def __init__(self, db_path: str | Path) -> None   # 只存 db_path，不开连接
    def init(self) -> None                             # 建表 + 索引（IF NOT EXISTS）

        # 校验流转；status=='ended' 时写 ended_at=now

    # trace_nodes

        content: Any, parent_id: str | None = None,
    ) -> None
    def get_node(self, node_id: str) -> TraceNode | None
    def list_nodes(self, session_id: str) -> list[TraceNode]   # 按 rowid 排序

    # decisions
    def create_decision(
        self, decision_id: str, session_id: str, tool_name: str,
        args: dict[str, Any],
        status: DecisionStatus = "pending",
        reason: DecisionReason | None = None,
    ) -> None
        # 初始状态即 resolved（allowed/rejected）时写 resolved_at=now；
        # rejected 缺 reason / 非 rejected 带 reason → ValueError
    def get_decision(self, decision_id: str) -> Decision | None
    def transition_decision(self, decision_id: str, status: DecisionStatus, reason: DecisionReason | None = None) -> None
        # 仅 pending→allowed/rejected；校验流转 + reason 约束；写 resolved_at=now
    def list_pending_decisions(self, session_id: str) -> list[Decision]   # status='pending'

## 5. mypy strict 已知坑（实现时注意）

- `json.loads` 返回 `Any`：读 metadata/args/content 时用 `cast(dict[str, Any], ...)` 或字段类型本就 `Any`。
- `sqlite3` 行取值（`row["status"]` 等）为 `Any`：`conn.row_factory = sqlite3.Row` 后仍需 `cast` 到目标类型再构造 frozen dataclass。
- 所有函数、方法、dataclass 字段带完整注解（`-> None`、`-> Session | None` 等）。
- 连接关闭用 `with closing(sqlite3.connect(...)) as conn:`（`from contextlib import closing`），避免手写 try/finally。
- 并发写可能触发 `sqlite3.OperationalError: database is locked`（SQLITE_BUSY）：本地单用户低并发，MVP 不引入超时重试，记为已知边界。
