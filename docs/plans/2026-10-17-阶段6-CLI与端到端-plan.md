## 2. 设计决策

| # | 决策 | 方案 | 理由 / 来源 |
|---|---|---|---|
| D1 | 自动开浏览器 | `serve` 默认启动后开浏览器；加 `--no-browser` 关闭。`_serve` 里 spawn 一个 daemon `threading.Timer(1.0, webbrowser.open, ...)`，1s 延迟等 uvicorn 绑定完成 | 标准库 `webbrowser` 零新依赖；路线 §4「补全自动开浏览器」 |
| D2 | 浏览器 URL | `http://{host}:{port}/`；host 为 `0.0.0.0` 时 URL 用 `127.0.0.1`（否则浏览器打不开通配地址） | 默认 host 已是 `127.0.0.1`，此为兜底 |
| D3 | cli 可测性 | 抽出 `_open_browser(host, port)` 纯函数；`_serve` 只编排「要不要开 + 开完跑 uvicorn」。测试用 monkeypatch `webbrowser.open` + `_serve` | 不让单测真弹浏览器 |
| D4 | examples 形态 | 单文件 `examples/react_demo.py`，`argparse --scenario {degrade,loop,breakpoint}`；工具集 `search`/`fetch`（普通）+ `send_email`（`suspend=True`） | 只 `from lens import ...`，判定全在后端（不变量 2） |
| D5 | examples 降级 | `degrade` 场景不依赖看板；SDK 静默降级（`start_session()` 返回 None、工具直接执行），脚本无需任何特殊分支 | 不变量 1「不起看板照常跑」 |
| D6 | examples 断点 | `breakpoint` 场景 `send_email` 命中挂起 → 用户前端放行→正常返回 / 拒绝→抛 `ToolRejected` → 脚本捕获走错误分支打印 | 不变量 4；演示「非致命异常走错误分支」 |
| D7 | e2e 架构 | 真实 `uvicorn.Server`（daemon 线程 + 自由端口 + tmp db），SDK 走真实 httpx + `LENS_BASE_URL`；**不用 TestClient** | TestClient 是 in-process ASGI，测不出真实 uvicorn 的 WS 层（交接已知坑 1） |
| D8 | SDK 单例重置 | autouse fixture 每用例前 `lens.sdk.client._default_client = None` + 清 `trace._suspend_tools`/`trace._current_session`；`LENS_BASE_URL` 由 `server_url` fixture（或用例体，degrade 场景）设置 | `get_default_client()` 惰性单例读 env；单例残留会指向旧端口。**工具在测试函数内定义**（`@bind_tool(suspend=True)` 装饰时机先于 `start_session()`，保证 suspend 注册在 autouse 清空之后生效） |
| D9 | 挂起 e2e 并发 | breakpoint 场景 SDK 调用放后台线程（`timeout=None` 阻塞），主线程轮询 `pending_decisions` 后 `resolve` | 同阶段 3 test_suspend 模式，但走真实 HTTP 而非 ASGI |
| D10 | 真实 WS 握手 | `websockets.sync.client.connect`（已是运行时依赖）连 `/v1/stream`，建会话后断言收到 `session_status` | 覆盖「websockets 依赖缺失 → /v1/stream 404」坑，TestClient 覆盖不到 |
| D11 | 打包依赖 | `build` 前端实测缺失（`.venv` 无 `build` 模块）；加 `build>=1.2` 到 `[project.optional-dependencies].dev` + 记 `docs/decisions/` | CLAUDE.md「新增依赖必须记入 docs/decisions」；`build` 是 dev-only 打包前端，不进 `dependencies` |
| D12 | 打包冒烟 | `.venv/bin/python -m build` 产 wheel/sdist 到 `dist/`（已 gitignore）→ 新建干净 venv `pip install dist/*.whl` → `lens serve --no-browser` → curl `/health` + 真实 WS 握手 | 确认新环境 websockets 被正确带入、WS 正常（交接红线 5）；不发布 |

## 3. 文件结构

### 3.1 `lens/cli.py`（改动）

- `serve_parser.add_argument("--no-browser", action="store_true", help="启动后不自动打开浏览器")`。
- `main()`：`command == "serve"` 分支传 `no_browser`。
- 新增 `_open_browser(host: str, port: int) -> None`：算 URL（D2）→ `webbrowser.open(url)`。
- `_serve(host, port, no_browser)`：`no_browser` 为假则 `threading.Timer(1.0, _open_browser, args=(host, port)).start()`（daemon）→ `uvicorn.run(...)`。

### 3.2 `examples/react_demo.py`（新增，脚本化 ReAct，无真实 LLM）

- 工具：`@bind_tool() search(query)` / `@bind_tool() fetch(url)` / `@bind_tool(suspend=True) send_email(recipient)`。
- `run_degrade()`：`start_session()` → 打印是否连上看板 → 顺序跑 `search`/`fetch` → `end_session()`。有无看板都照常。
- `run_loop()`：`start_session()` → 循环 3 次 `search("相同查询")` → 第 3 次抛 `AgentLoopException` → 捕获打印终止 → `end_session()`。
- `run_breakpoint()`：`start_session()` → `log_thought(...)` → `search(...)` → `send_email(...)`（挂起等前端）→ allow 打印结果 / 捕获 `ToolRejected` 打印「被拒绝，走错误分支」→ `end_session()`。
- `main()`：`argparse --scenario {degrade,loop,breakpoint}`（默认 `breakpoint`）。

### 3.3 `tests/test_cli.py`（新增）

- `test_serve_parser_has_no_browser`：monkeypatch `sys.argv` + `_serve`，断言 `--no-browser` 解析并传入 `_serve`。
- `test_open_browser_calls_webbrowser`：monkeypatch `webbrowser.open`，断言 `_open_browser("127.0.0.1", 7878)` 打开 `http://127.0.0.1:7878/`；`0.0.0.0` 映射 `127.0.0.1`。

### 3.4 `tests/test_e2e.py`（新增，5 个用例）

- fixture `server_url`（function 级）：找自由端口 → `uvicorn.Server(uvicorn.Config(create_app(tmp_path/"e2e.db"), host="127.0.0.1", port=free_port, log_level="error"))` → daemon 线程 `server.run()` → 轮询 `server.started` → `monkeypatch.setenv("LENS_BASE_URL", base_url)` → yield base_url → teardown `server.should_exit = True` + join。
- fixture `_reset_sdk_state`（autouse）：重置 `client._default_client = None` + 清 `trace._suspend_tools`/`trace._current_session`（setup 与 teardown 各一次，D8）。
- 工具（含 `@bind_tool(suspend=True)`）在**每个测试函数内**定义，装饰时机先于 `start_session()`，避免 autouse 清空与模块级装饰的注册顺序冲突。
- `test_degrade_no_board`：指向死端口 → `start_session()` 返回 None → `@bind_tool` 工具正常执行、无异常。
- `test_loop_breaks_on_third`：`start_session()` → 同名同参工具 3 次 → 前两次正常、第 3 次抛 `AgentLoopException`。
- `test_breakpoint_allow`：suspend 工具后台线程调用（阻塞）→ 轮询 pending → resolve allow → 线程返回工具结果。
- `test_breakpoint_reject`：同上，resolve reject → 线程捕获 `ToolRejected`。
- `test_ws_real_handshake`：`websockets.sync.client.connect` 连 `/v1/stream` → HTTP 建会话 → 收到 `session_status`。

## 7. 红线（勿越界）

1. **智能放后端**：examples 只发 HTTP + 按响应分派，不做熔断/断点/相似度判定。
2. **降级保证**：degrade 场景必须「不起看板照常跑、不抛异常」。
3. **不改 `openapi.yaml` / 不改 `lens/server/` / 不改 `lens/sdk/` 逻辑**（e2e 测试只在测试里读 SDK 私有单例做重置，不改 SDK 实现）。
4. **打包不发布 PyPI**。
5. **不新增运行时依赖**：`build` 只进 dev extras，不进 `dependencies`。
6. **不用 worktree、不强制 formal review**，直接 main 分支实现。

---

## 8. 已知坑（实现时必读）

1. **websockets 依赖（最重要）**：pyproject 已加 `websockets>=12.0`；真实 WS 验证必须起真实 uvicorn（非 TestClient）。e2e 的 `test_ws_real_handshake` 与打包冒烟 §6.4 都走真实握手，防回归。
2. **`build` 前端缺失**：`.venv` 实测无 `build` 模块，Task 4 补进 dev extras 才能跑 `python -m build`。
3. **SDK 单例惰性**：`get_default_client()` 是进程级单例，读 env 只在首次构建；e2e 必须重置 `_default_client`（D8），否则跨用例指向旧端口。
4. **挂起是同步 HTTP 长挂**：SDK `execution_request` 用 `timeout=None` 阻塞；breakpoint e2e 必须放后台线程 + 主线程 resolve，否则死锁。
5. **无 `python` 命令**：统一 `.venv/bin/` 前缀；起后端 `.venv/bin/lens serve`。
6. **`_default_db_path` 落 home**：e2e 用 `create_app(tmp_path/"e2e.db")`，不碰 `~/.lens/lens.db`。
7. **suspend 名单进程级全局**：e2e 用 autouse 清 `trace._suspend_tools`，避免 `@bind_tool(suspend=True)` 跨用例串扰。
