# 新增 build 打包依赖

- 日期：2026-10-17
- 版本：v1.0
- 状态：已确认
- 前置阅读：`docs/plans/2026-10-17-0.1.0-实现路线.md`（§4 阶段 6、§5 打包决策）、`pyproject.toml`

---

## 背景

阶段 6 需做打包验证：`python -m build` 产出 wheel/sdist + 安装冒烟（不发布 PyPI）。实测 `.venv` 无 `build` 模块（`python -m build` 报 `No module named build`），打包验证无法执行。

## 正文

`[project.optional-dependencies].dev` 新增 `build>=1.2`（PyPA 官方打包前端）。它只在开发期用于 `python -m build` 构建，**不进 `dependencies`**（运行时不需要），符合「依赖最小化」。

## 决策与权衡

- **方案 A（采用）**：加 `build>=1.2` 到 dev extras。官方标准前端，`pip install -e ".[dev]"` 自动带入，`python -m build` 直接可用；dev-only，不污染运行时依赖。
- **方案 B（弃）**：打包时临时 `pip install build` 不落 pyproject。省一条 dev 依赖，但后续开发者按门禁 `pip install -e ".[dev]"` 拿不到 build，打包验证不可复现。
